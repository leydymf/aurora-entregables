# Aurora — Entregables del proyecto de grado

Documentos de entrega del proyecto de grado «Aurora: prototipo de aplicación móvil de uso discreto para el acceso a información, la orientación y el registro seguro ante la violencia de género en mujeres de Santander». Universidad Autónoma de Bucaramanga, Ingeniería de Sistemas, 2026. Autora: Leydy Yohana Macareo Fuentes. Directora: Verónica Chajín Ortiz.

El código de la aplicación está en https://github.com/leydymf/aurora-app.
